# AI Recipe Generator

Generate complete, balanced, USDA-verified recipes from simple natural language text descriptions.

---

## Generating a Recipe

1. Navigate to **Recipes 🍳** and click **🧑‍🍳 Generate with AI**.
2. Enter a description of your recipe idea (e.g., _"Creamy garlic chicken bowl with asparagus and brown rice"_).
3. Select category (**Meal** or **Snack**).
4. Toggle **Target My User Settings Macros** to automatically align the recipe yield to your target macro splits. (or choose not to provide targets to give the AI more creative freedom)
5. Select any dietary restrictions and click **Generate Recipe**.

---

## Ingredient Verification Waterfall

Every ingredient generated by AI passes through a 3-stage resolution pipeline:

1. **Local DB Match**: Matched against verified system ingredients.
2. **USDA API Lookup**: Looked up via USDA FoodData Central and saved globally if macros are found.
3. **AI Fallback Estimation**: Estimated safely using AI generated nutrition information if absent from USDA.
