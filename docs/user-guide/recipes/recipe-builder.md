# Recipe Builder

The **Recipe Builder** allows you to create custom recipes with real-time per-portion macronutrient calculations.

---

## Creating a Recipe

1. Go to **Recipes 🍳** and click **+ Create Custom Recipe**.
2. Enter a **Recipe Title**, category (**Meal** or **Snack**), and access level (**Public** or **Private**).
3. Set the number of **Portions** (recipe yield), preparation time, description, and step-by-step instructions.

---

## Adding Ingredients

1. Click **+ Add Ingredient** to search the ingredient database.
2. Select an ingredient from the search results or create a custom ingredient if needed.
3. Enter the physical **Weight (g)** used in the recipe yield.
4. Optionally enter human-readable display amounts (e.g., `2` `tbsp` or `1` `cup`).

!!! info "Real-Time Macro Feedback"
As you adjust ingredient weights or recipe yield portions, the top banner updates per-portion calories, protein, net carbs, and fat in real time, highlighting how close the recipe is to your personal target.
