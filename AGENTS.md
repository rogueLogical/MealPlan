## Agent skills

### Issue tracker

GitHub Issues are the repo's source of truth for work. See `docs/agents/issue-tracker.md`.

### Triage labels

The canonical triage vocabulary is `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses the single-context layout: root domain context docs plus `docs/adr/` are the primary domain references. See `docs/agents/domain.md`.
